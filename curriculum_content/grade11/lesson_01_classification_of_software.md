## Blocks

### Block 1

- block_type: heading
- heading_level: h1
- content: Classification of Software

### Block 2

- block_type: text
- content:

Software is the set of programs and related instructions that tell computer hardware what to do. Hardware by itself can store data and process signals, but software gives it useful behaviour: starting the computer, managing files, opening a document, editing an image, browsing the web, or running a game.

For this lesson, software is classified into two main categories:

1. System software
2. Application software

The key question is: who or what is the software mainly serving? If it mainly helps the computer system operate, manage resources, or support other programs, it is system software. If it mainly helps the user complete a task, it is application software.

### Block 3

- block_type: heading
- heading_level: h2
- content: The Main Classification

### Block 4

- block_type: text
- content:

Software can be organised as a simple classification tree:

Software

System software:
- Operating systems
- Utility programs
- Library programs
- Translator software

Application software:
- General-purpose software
- Special-purpose software
- Bespoke software

This structure is useful because it separates programs that keep the computer working from programs that help people solve everyday or professional tasks.

### Block 5

- block_type: heading
- heading_level: h2
- content: System Software

### Block 6

- block_type: text
- content:

System software is software that manages and controls the computer system. It works close to the hardware and provides a platform for application software to run.

System software usually performs one or more of these roles:

- manages hardware resources such as the CPU, memory, storage, and input/output devices;
- provides an interface between the user, applications, and hardware;
- starts and maintains the computer system;
- supports security, file management, configuration, and performance;
- helps programmers translate or reuse code when developing new programs.

For example, a virus scanner is system software because its main purpose is to protect and maintain the computer system. A file manager is also system software because it helps organise files and folders on the storage device.

### Block 7

- block_type: heading
- heading_level: h2
- content: Types of System Software

### Block 8

- block_type: text
- content:

Operating systems are collections of programs that manage hardware resources and provide common services for applications. An operating system allows users and applications to work with the computer without controlling the hardware directly. It can manage memory, processor time, files, input/output devices, users, and security.

Utility programs are system tools designed for a specific maintenance or management task. Examples include antivirus tools, file managers, backup tools, compression tools, disk cleanup tools, and system monitors. Their focus is the health, configuration, performance, or organisation of the computer system.

Library programs are collections of ready-made routines that other programs can use. They save development time because programmers do not need to write common functions again and again. Libraries may provide routines for printing, drawing graphics, playing sound, connecting to networks, or building user interfaces.

Translator software converts program code into a form that a processor can execute. The main types are assemblers, compilers, and interpreters. An assembler translates assembly language into machine code. A compiler translates a whole high-level program into executable object code. An interpreter translates and runs high-level code step by step while the program is executing.

### Block 9

- block_type: heading
- heading_level: h2
- content: Application Software

### Block 10

- block_type: text
- content:

Application software is designed to help users perform specific tasks. It is usually more user-focused than system software because the user opens it to create, calculate, communicate, design, analyse, search, learn, or play.

The main purpose of application software is not to manage the computer itself, but to use the computer as a tool for a human activity. For example, a word processor helps a user write a letter or report. A spreadsheet helps a user organise data and perform calculations. A graphics editor helps a user create or modify images.

The same rule works in professional contexts. Payroll software helps a company calculate salaries. Stock control software helps a warehouse track items. A booking system helps a business manage reservations. These are application programs because they support user or organisation tasks.

### Block 11

- block_type: heading
- heading_level: h2
- content: Types of Application Software

### Block 12

- block_type: text
- content:

General-purpose application software can be used for many different tasks. A word processor can be used for letters, essays, instructions, forms, and reports. A spreadsheet can be used for budgets, marks, invoices, calculations, charts, and data analysis. General-purpose software is flexible because the user decides how to apply it.

Special-purpose application software is designed for one main task or a narrow set of related tasks. Examples include web browsers, payroll systems, stock control systems, booking systems, route planners, and school timetable systems. It may be complex, but its purpose is focused.

Bespoke application software is custom-made for one client or organisation. It is used when ready-made software does not fit the organisation's workflow, security requirements, scale, or business rules. Bespoke software can match a client's needs very closely, but it is usually more expensive and slower to develop.

### Block 13

- block_type: heading
- heading_level: h2
- content: How to Classify Software

### Block 14

- block_type: text
- content:

To classify a program, do not start with its brand name. Start with its purpose.

Ask these questions:

1. Does it mainly operate, control, protect, maintain, or support the computer system?
   If yes, it is system software.

2. Does it mainly help the user complete a task?
   If yes, it is application software.

3. If it is system software, is it an operating system, utility, library, or translator?

4. If it is application software, is it general-purpose, special-purpose, or bespoke?

Examples:

- Word processor: application software, general-purpose
- Operating system: system software, operating system
- File manager: system software, utility
- Compiler: system software, translator
- Payroll system: application software, special-purpose
- Custom banking platform made for one bank: application software, bespoke
- Graphics library used by several programs: system software, library

### Block 15

- block_type: heading
- heading_level: h2
- content: System Software vs Application Software

### Block 16

- block_type: text
- content:

System software and application software differ by purpose, position in the computer system, and user focus.

System software manages the computer system. It works as a foundation for other programs. It often starts automatically or runs in the background. It communicates closely with hardware and provides services to applications.

Application software helps users perform tasks. It usually runs on top of system software. It is opened when the user needs a particular tool, such as writing text, editing an image, browsing web pages, managing stock, or calculating payroll.

A simple way to remember the difference:

- System software helps the computer work.
- Application software helps the user work.

### Block 17

- block_type: heading
- heading_level: h2
- content: Key Terms

### Block 18

- block_type: text
- content:

System software: software that manages the computer system and provides a platform for applications.

Application software: software that helps users perform specific tasks.

Operating system: system software that manages hardware resources and provides services for applications.

Utility program: system software that performs a specific maintenance or management task.

Library program: reusable routines and services used by other programs.

Translator software: software that converts source code into machine code or another executable form.

General-purpose software: application software that can be used for many different tasks.

Special-purpose software: application software designed for one main task or a narrow task area.

Bespoke software: application software custom-made for a specific client or organisation.

## Teacher Notes

For exam-style answers, encourage students to use category names rather than brand names. For example, "word processor" is a software type; a specific commercial product name is only an example and may not earn classification marks by itself.
