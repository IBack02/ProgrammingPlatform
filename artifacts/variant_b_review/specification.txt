1. AIM OF THE SUMMATIVE ASSESSMENT FOR THE TERM 
 
Summative assessment (SA) is aimed at assessing learners’ success in terms of the 
achievement of the learning objectives and revealing their level of knowledge and skills acquired 
during the term. 
Summative assessment checks the achievement of learning objectives for the term planned in 
the course plan.  
 
2. THE DOCUMENT DEFINING THE CONTENT OF THE SUMMATIVE ASSESSMENT 
FOR THE TERM 
 
Subject program for “Computer Science” (advanced level), Grades 11-12 (Issue 2.0, 2026). 
 
3. EXPECTED OUTCOMES ON THE SUBJECT “COMPUTER SCIENCE”, GRADE 11 
 
• 
Data Representation & Architecture: 
o can explain the differences between binary, decimal, and hexadecimal number 
systems, perform arithmetic operations (addition, multiplication) in binary, and 
convert values between base systems; 
o understand how bitmap images and digital audio are stored, and calculate the file 
sizes of bitmap images, text fragments (using ASCII and Unicode), and audio data; 
o explain the impact of resolution, color depth, sampling rate, and bit depth on media 
file size and quality; 
 
• 
Web Programming & Database Systems: 
o can design relational databases with multiple related tables using appropriate primary 
and foreign keys and data types; 
o can write advanced SQL queries, including SELECT queries with JOIN operations, 
to extract data from multiple tables; 
o can develop responsive web interfaces using HTML tags, CSS styles, and implement 
clear site navigation; 
o can process user input from HTML forms using procedural server-side scripts (e.g., 
PHP) while incorporating algorithms for data validation and verification; 
o can manipulate one-dimensional and two-dimensional arrays using selection 
(branching) and iterative (loop) algorithms in program code; 
o can establish procedural script connections to databases to dynamic insert, retrieve, 
and display records on web pages; 
 
• 
Network Technologies & Web Architecture: 
o can distinguish between Local Area Networks (LAN) and Wide Area Networks 
(WAN), as well as Intranet and Internet architectures; 
o can compare client-server and peer-to-peer network models, highlighting their 
structural advantages and operational trade-offs; 
o can evaluate wired versus wireless connection mediums, and compare network 
topologies (bus, ring, star, mesh); 
o understand the purpose and operational roles of hardware networking devices 
(repeaters, hubs, switches, routers, gateways); 
o can explain the structure of URLs, the role of IP and MAC addresses in packet 
routing, and the purpose of the Domain Name System (DNS); 
o can explain the functions of standard network application protocols (HTTP, HTTPS, 
FTP, FTPS, POP3, SMTP);

6. ADMINISTRATION RULES  
During the Assessment cover all visual materials like diagrams, schemes, posters, and maps 
that can serve as prompts for the learners. 
At the beginning of the Assessment read out the instructions and inform the learners about the 
assessment duration. Remind learners that they are not allowed to talk with each other during the 
Summative Assessment. After the instructions, make sure they have understood the given 
instructions and ask if they have any questions before the start of the assessment. 
Ensure that the learners are working individually and not helping each other. During the 
Summative Assessment, learners should not have any access to additional resources that can help 
them, for example, dictionaries (excluding the cases when it is allowed in the specification). 
Recommend learners to cross the wrong answers instead of using an eraser.  
During the assessment, you can answer learners’ questions regarding the instructions and the 
assessment duration. You should not spell, paraphrase, or provide any information that could give 
the learner an advantage.  
Always tell the learners that they have 5 minutes left before the end of the Summative 
Assessment. 
Tell the learners to stop writing and put down their pens/pencils on the desks at the end of the 
Summative Assessment. 
 
7. MODERATION AND MARKING 
All teachers use the same version of the mark scheme. During the moderation process it is 
necessary to check learner sample papers with the marks awarded to ensure there are no deviations 
from the standardized mark scheme.

SPECIFICATION OF SUMMATIVE ASSESSMENT FOR TERM 1 
Review of summative assessment for Term 1 
 
Duration of the summative assessment – 80 minutes 
Total marks - 40 
 
Type of tasks: 
MCT – multiple choice tasks. 
SA – tasks that require a short answer; 
EA – tasks requiring an extended answer. 
 
The structure of the summative assessment 
 
This option consists of 22 tasks, including structured tasks with brief and detailed answers. 
 
In multiple-choice questions, you must select only one answer option. 
 
In questions requiring a short answer, the student writes down the answer in the form of a 
numerical value, a word, or a short sentence. 
 
In questions that require a detailed answer, the trainee must demonstrate the entire sequence 
of actions taken to solve tasks to obtain the maximum score. A task can contain several structural 
parts / sub-questions.
