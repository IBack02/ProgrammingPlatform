# Изображения помощников

Все 12 предоставленных PNG подключены вместо заглушек в опубликованных наборах версии 2. Изображения переименованы по идентификаторам персонажей и перенесены из вложенной папки `чиби/` сюда. Пиксели, размер 1254×1254 и прозрачность сохранены. Генерация изображений не использовалась.

Предпочтительный формат — PNG с прозрачным фоном. Персонаж целиком, без обрезанной головы или ног, с небольшими полями. Рекомендуемый размер 512–1536 px; квадратный холст удобнее, но прямоугольный тоже поддерживается. Изображения копируются без обрезки, растяжения или удаления прозрачности.

Предоставленные ресурсы находятся в `tower/static/tower/sets/<id>/v2/companion.png` и загружены в Cloudflare R2. На Render применить миграцию `0013_publish_chibi_art` и выполнить `collectstatic`. Миграция обновляет графику уже полученных помощников, сохраняя выбранные предметы, коллекцию и валюту. Старые SVG в версии 1 остаются только для неизменяемой истории публикаций.

Для будущей замены: `python manage.py import_tower_chibi`. Команда проверяет файлы, копирует их в каталог ресурсов и обновляет ссылки/размеры. Для опубликованного набора создаётся новая черновая ревизия; старые изображения сохраняются. Новую ревизию публикуют через `publish_character_sets --hero ID`. Для проверки без записи: `python manage.py import_tower_chibi --dry-run`.
