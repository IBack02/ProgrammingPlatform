# Изображения помощников

Сюда можно положить свои чиби. В проекте пока используются нейтральные SVG-заглушки; генерация персонажей отключена по просьбе владельца.

Предпочтительный формат — PNG с прозрачным фоном. Персонаж целиком, без обрезанной головы или ног, с небольшими полями. Рекомендуемый размер 512–1536 px; квадратный холст удобнее, но прямоугольный тоже поддерживается. Изображения копируются без обрезки, растяжения или удаления прозрачности.

После добавления файлов: `python manage.py import_tower_chibi`. Команда проверяет файлы, копирует их в каталог ресурсов и обновляет ссылки/размеры. Для опубликованного набора создаётся новая черновая ревизия; старые изображения сохраняются. Новую ревизию публикуют через `publish_character_sets --hero ID`. Для проверки без записи: `python manage.py import_tower_chibi --dry-run`.
