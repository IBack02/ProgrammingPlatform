# Награды коллекционного журнала

Вход учителя: `/teacher/tower/`. Выбранный класс общий для выдач, правил и истории. Настройки доступа к журналу находятся внизу страницы. Прежний адрес `/teacher/tower/wallets/` и API одиночной выдачи сохранены.

## Ручная выдача

Выберите учеников, сумму на каждого и общую причину. Итоговая сумма показывается до отправки. «Выбрать всех» действует на текущую страницу списка (до 50 учеников); поиск и переход между страницами сбрасывают выбор. Выдача атомарна: ошибка у любого получателя отменяет всю группу. Повтор запроса с тем же UUID возвращает прежний результат; изменение получателей, суммы или причины с этим UUID отклоняется.

## Автоматические правила

Правила задаются для класса и распространяются на доступные ему занятия. По умолчанию суммы равны нулю: ничего не начисляется до настройки учителем. 0 отключает соответствующую награду.

- Гонки умов: отдельные суммы за 1–3-е места, по убыванию. Начисление при завершении гонки учителем. Участники, не прошедшие все задания, награду не получают, даже если платформа присвоила им итоговое место. Каждая новая гонка может принести новый приз.
- Программирование: первое принятое проверяющей системой решение конкретной задачи.
- Тесты: первое выполнение конкретного теста со всеми правильными ответами; используется сумма за решение.
- Теория: первое успешное открытие конкретной страницы при включённой награде. Повторное открытие не приносит дополнительные монеты.

Повторные запросы, изменение суммы и переход ученика между классами не дублируют уже полученную награду за один ресурс. Изменение правил не пересчитывает историю. Старые результаты не обходятся и не оплачиваются задним числом. Доступ проверяется заново: общий выключатель, разрешение учителя, включённый класс, активный ученик и принадлежность занятия классу. Гости исключены.

Все начисления используют существующий кошелёк, неизменяемый журнал операций и аудит. Изменение правил также сохраняется в аудите. В истории учителя видны его выдачи и автоматические награды принадлежащего ему класса; у ученика сохраняется общий баланс.

## Проверка

Миграция: `python manage.py migrate`.
Статические файлы перед запуском с manifest storage: `python manage.py collectstatic --noinput`.
Проверки: `python manage.py test tower core.tests_game_modules core.tests_multiclass_sharing core.tests_lesson`.
Для локального окружения без production SECRET_KEY используется переменная `DEBUG=true`. Тесты конкурентного доступа к кошелькам требуют PostgreSQL; на SQLite они пропускаются.
