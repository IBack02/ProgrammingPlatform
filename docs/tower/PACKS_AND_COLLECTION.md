# Паки и личная коллекция

Ученик открывает `/tower/`. Баланс и коллекция общие для всех его разрешённых классов.

- **Коллекция:** 12 персонажей, фильтры по редкости и состоянию, прогресс из 10 фрагментов, биографии и до трёх избранных собранных карточек. Неоткрытые персонажи показаны силуэтами.
- **Паки:** покупка сразу определяет и сохраняет результат. История доступна страницами по 10 открытий; старый результат можно открыть снова без списания.
- **Кошелёк:** нишкойны, универсальные осколки и неизменяемая история всех операций.
- **Аватарка:** бесплатные форма и цвет, магазин постоянных украшений, выбор приобретённых вещей и темы журнала. Новые игровые раунды используют сохранённую внешность; старые сохраняют свой снимок.

## Начальная экономика

`school-v1`: пак за **50 нишкойнов**, три слота по два фрагмента. Для сборки нужны 10 фрагментов. В каждом обычном слоте: обычная редкость 70%, редкая 22%, эпическая 7%, легендарная 1%. Внутри редкости три персонажа равновероятны.

После четырёх паков подряд без редкого+ первый слот следующего пака гарантирует редкого+ с весами 22:7:1. Любой редкий+ сбрасывает счётчик. Отдельной легендарной гарантии нет. Эти правила показаны до покупки.

Переполнение собранной карточки превращается в универсальные осколки 1:1. Цена нужного фрагмента: обычный — 2, редкий — 4, эпический — 8, легендарный — 16 осколков. Обмен доступен в деталях карточки, стоимость показывается до отправки. Собрать уже собранную карточку или переполнить её обменом нельзя.

Украшения: кепка 30, круглые очки 40, тёмные очки 60, корона 80, усы 35, каждая дополнительная тема 100 нишкойнов. После покупки предмет нужно выбрать и сохранить в настройках внешности. Денежных платежей и переводов между учениками нет.

## Запуск и обновление каталога

```text
python manage.py migrate
python manage.py seed_tower_catalog
python manage.py collectstatic --noinput
python manage.py reconcile_tower_wallets
```

Для локального окружения без production SECRET_KEY задаётся `DEBUG=true`. Настройки доступа и общий `TOWER_ENABLED` остаются обязательными. Команда каталога не включает доступ и не создаёт игровых аккаунтов или стартовых наград.

Цены и вероятности берутся из опубликованной серверной версии. Манифесты: `tower/content/cards.json` и `tower/content/economy.json`. Повтор seed идемпотентен; менять опубликованную конфигурацию под тем же slug нельзя. Для новой конфигурации задаётся новый `version`; seed переключает предложение и пишет событие аудита, сохраняя выключенное состояние предложения. Старые версии, открытия и проводки не удаляются. Суперпользователь может выключить предложение в админке, остальные записи каталога и приобретений доступны только для чтения.

Покупка, списание, сборка, переполнение и снимок результата атомарны. Сервер проверяет цену и собственность; браузер передаёт только ID предложения/версии и UUID. Повтор запроса возвращает исходное открытие. Тот же UUID с другой версией/целью отклоняется. Неуспешная покупка не меняет ни кошелёк, ни гарантию, ни коллекцию. После потери соединения сначала можно повторить запрос или проверить историю.

Публичные профили одноклассников и присутствие на модулях остаются следующими самостоятельными этапами плана. Они не нужны для покупок, сборки и персонализации своего журнала.
