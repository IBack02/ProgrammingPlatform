Этап 6, 26 октября 2026 года. Реализован и проверен локально. Все 12 наборов опубликованы в локальном каталоге, 72 ресурса проверены; реальные чиби по прежнему решению владельца заменены нейтральными заглушками. Внешнее развёртывание и публикация в R2 не выполнялись.

## Поведение

Выбранный помощник проверяет наличие источника без генерации. Красный «!» означает возможность получить новую реплику по кнопке «Напомни о важном». После нажатия появляются три точки; сохранённый ответ содержит проверенную сервером ссылку на материал, работу или экзамен. Закрытие виджета не удаляет реплику. Перезагрузка читает тот же результат из базы без повторного обращения к OpenAI.

Один интервал **30 минут на аккаунт** начинается после сохранения проверенного ответа. Он общий для всех вкладок, устройств, языков и персонажей. Смена чиби, отключение или повторное включение функции его не сбрасывают. При ошибке модели интервал не начинается; короткая задержка повтора составляет минимум 30 секунд. При неопределённом исходе сетевого запроса повтор блокируется до конца 90-секундного резерва, чтобы не запустить параллельную генерацию.

Комментарий считается разобранным только после подтверждения отображения сохранённой реплики. Скрытый, свёрнутый или находящийся вне видимой области виджет подтверждение не отправляет. Сохранённый ответ остаётся доступен после изменения учебного прогресса, пока ученик имеет право на связанный источник; права и ссылка проверяются заново. Источник для новой генерации заново выбирается по правилам этапа 5.

На странице прохождения экзаменов и в игровом модуле виджет скрыт. Сервер также блокирует генерацию при собственной активной экзаменационной попытке или участии в запущенной игре, включая запрос из другой вкладки. Виджет размещён в обычном потоке документа: в боковой панели урока или в отдельной области страницы. Он не перекрывает код и кнопки. Учтены клавиатура, узкая ширина и reduced motion.

## OpenAI и сохранение

Используется существующий серверный клиент `core.ai_assist._get_openai_client`, Responses API и Structured Outputs. Модель по умолчанию — `gpt-4o-mini`; конфигурация помощника независима от остальных функций ИИ приложения. Запрос имеет два отдельных сообщения: системные правила и снимок характера, затем ограниченные учебные данные. В нём нет скрытых эталонных ответов, исходного кода ученика, других учеников, ключа API или произвольных ссылок клиента.

Модель возвращает два текстовых поля; итог проверяется на 2–4 предложения, 20–600 символов, пустые поля, код, ссылки, лишние JSON-символы и соответствие письменности выбранному языку. Это проверка формы и части ограничений, а не доказательство фактической точности любого будущего ответа. Ссылку добавляет сервер, текст показывается через `textContent`. Для незавершённой работы промпт требует напоминание о действии без готового алгоритма; смысл замечания учителя сохраняется.

Таймаут по умолчанию 20 секунд, автоматические повторы SDK отключены. Сетевое ожидание находится **за пределами транзакции**. Короткие транзакции блокируют строку ученика при резервировании и сохранении. Любой параллельный клик привязывается к одному сообщению; UUID запроса сохраняется и при повторной доставке не запускает новый вызов. Поздний ответ истёкшей или заменённой операции отклоняется.

`CompanionAccountState` хранит общий интервал, задержку повтора и текущую операцию; `CompanionRequest` — соответствие UUID и сообщения. `CompanionMessage` сохраняет версию характера, язык, статус, модель, доступный расход входных/выходных токенов, длительность и ID запроса провайдера. При сетевой ошибке неизвестный расход хранится как неизвестный. Доступные метрики ответа сохраняются и при его отклонении проверкой. Логи содержат тип ошибки и ID операции, без ключа и учебного текста.

Официальные источники: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Python SDK: ошибки, повторы и таймауты](https://developers.openai.com/api/reference/python).

## API

- `GET /api/tower/companion/status/?surface=learning`: состояние `inactive`, `quiet`, `unavailable`, `empty`, `ready`, `generating`, `retry_wait` или `cooldown`, ближайшее время и последняя доступная сохранённая реплика. Проверка не вызывает модель и не создаёт операции.
- `POST /api/tower/companion/generate/`: JSON с `request_id` (UUID) и необязательным `surface` (`learning`, `game`, `exam`). Язык и выбранный персонаж определяются сервером. Долгий запрос возвращает сохранённый результат либо состояние ожидания/ошибки; другой клик во время обработки получает текущую операцию.
- `POST /api/tower/companion/acknowledge/`: JSON с `message_id` и необязательным `surface`, подтверждающий реальный показ.

Маршруты требуют действующей ученической сессии и допуска коллекции; POST защищены CSRF, входное тело ограничено. Состояние не кешируется. Клиент не выбирает чужой аккаунт, источник, характер или текст. При потере соединения виджет сначала проверяет сохранённое состояние, а не повторяет генерацию автоматически.

## Пилотное включение

`TOWER_COMPANION_ENABLED` по умолчанию выключен и независим от `TOWER_ENABLED`. Отключение генерации сохраняет валюты, коллекцию, внешний вид, историю и интервал. `TOWER_COMPANION_CLASS_IDS` — список числовых ID классов через запятую. Непустой список ограничивает пилот этими классами с действующим допуском коллекции; пустой список при включённом флаге допускает все разрешённые классы.

Для первого серверного выпуска указать ID одного реального класса. В секретных переменных сервиса настроить `OPENAI_API_KEY`, затем параметры:

```text
TOWER_ENABLED=true
TOWER_COMPANION_ENABLED=true
TOWER_COMPANION_CLASS_IDS=42
TOWER_COMPANION_MODEL=gpt-4o-mini
TOWER_COMPANION_TIMEOUT=20
```

`42` — пример, его заменяют ID выбранного класса. Ключ не помещают в исходники, HTML или промпты. Проверки перед включением:

```text
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py check_character_sets --require-published
python manage.py check_companion_readiness --class-id 42 --require-api-key
python manage.py evaluate_companions --live --limit 36
```

`evaluate_companions` без `--live` проверяет промпты без сетевых запросов. При явном `--live` использует только искусственные учебные примеры; результат и доступные метрики записываются в JSON. Команда готовности проверяет ресурсы, определения в БД, допуск класса и наличие переменной ключа; она не проверяет действительность ключа сетевым запросом.

Локальный пилот выполнен в отдельной тестовой базе и одном тестовом классе. В рабочем проекте флаг генерации оставлен выключенным по умолчанию; production и реальные классы не изменялись.

## Полный каталог и миграции

Миграция `0009_companion_generation` добавляет состояние генерации, идемпотентные запросы и метрики. `0010_publish_remaining_character_sets` содержит неизменяемые снимки оставшихся десяти наборов и повторяемое восстановление наград за ранее собранные карточки. Она не читает живые JSON-файлы, не создаёт фиктивные денежные проводки и сохраняет прежние покупки, оформление, более новые публикации и намеренные паузы.

Созданы 30 новых растровых ресурсов (головные уборы, предметы и фоны) через встроенный imagegen и 20 деталей интерфейса в существующем SVG-стиле. Все окончательные файлы находятся в `tower/static/tower/sets/<hero>/v1/`. Чиби не генерировались. Точные промпты и исходные пути: [SET_RELEASE_ART.json](SET_RELEASE_ART.json). Обычная Django-статика обеспечивает выдачу файлов без обязательной загрузки в R2.

Учительский предпросмотр и публикация поддерживают все опубликованные наборы. Упаковка для отдельной загрузки: `python manage.py prepare_character_assets --all --archive artifacts/tower/character-sets/all-sets-v1.zip`. Публичную копию можно отдельно проверить параметром `--verify-public-base`; успешная локальная упаковка не означает внешнюю загрузку.

Замена чиби собственным файлом создаёт новую черновую ревизию, сохраняя оригинал; после отдельной публикации новая графика применяется к постоянным компонентам. Подробности — [README чиби](../chibi/README.md).

## Результаты проверки

- Полный PostgreSQL-прогон: **354 теста успешно**, включая конкурирующие клики, один вызов провайдера и проверку отсутствия транзакции во время сети. SQLite: 354 теста, 13 проверок PostgreSQL-блокировок пропущены, остальные успешны.
- Финальный живой прогон: **36 из 36** примеров прошли проверку формата, 12 профилей × ru/kk/en. Доступный расход: 28 216 входных и 2008 выходных токенов; средняя длительность 2347 мс, максимальная 3750 мс. Отчёт: `artifacts/tower/character-sets/companion-evaluation.json`.
- Просмотрены соответствие смыслу искусственного источника, доброжелательность, отсутствие кода и готового решения. Различия характеров умеренные на коротких напоминаниях и заметнее в метафорах химика, художника и физика. Качество языка и полезность стоит дополнительно оценить с учителем в реальном пилоте; выборка не гарантирует безошибочность всех будущих ответов.
- Все 72 ресурса проверены по размерам, хешам и прозрачности; 12 наборов просмотрены на пяти фигурах. Реальный виджет получил ответ OpenAI, восстановил его после перезагрузки и показал общий интервал. На ширине 390 px горизонтального расширения нет. Снимки: `companion-desktop.jpg`, `companion-mobile.jpg`, `release-gallery.jpg` в том же каталоге артефактов.
- Локальные миграции применены после SQLite backup. Балансы, количество денежных проводок и выбранное оформление до и после миграций совпали. Django check, проверка отсутствующих миграций и сборка статики прошли.
