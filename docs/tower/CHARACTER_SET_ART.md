Загрузчики, декор и нейтральные заглушки созданы как небольшие редактируемые SVG. Запросы и происхождение растров — `SET_ART_PROMPTS.json`.

## Просмотр и крепления

Адрес для назначенного учителя или superuser: `/teacher/tower/sets/preview/`. На странице есть два комплекта, изменение шапки/предмета/фона, размеры 46/96/160 px, точки крепления и все четыре сочетания на пяти фигурах. Просмотр не создаёт игровых аккаунтов, владения или денежных операций.

У кепки pivot `(0.5, 0.707)` и относительная ширина 1.26; у берета `(0.5, 0.719)` и ширина 1.30. Это точки нижнего центра головного убора в полном холсте с прозрачными полями. Опора предметов `(0.5, 0.5)`, относительная ширина 0.84. Общая геометрия фигур сохранена, индивидуальные поправки находятся в компонентах.

Реальный браузерный просмотр подтвердил посадку на пяти фигурах и смешивание берета с контроллером, кепки с палитрой; кадр сохранён в `artifacts/tower/character-sets/pilot-preview.png`. Статусы черновиков сохраняются до публикации на этапе 3. Заглушка чиби допустима и всегда помечена `placeholder=true`; она не выдаётся за готовое изображение.

## Публикация изображений

Ресурсы находятся в `tower/static/tower/sets/<hero>/v1/`; они доступны обычной публикацией `collectstatic`, поэтому предпросмотр не зависит от ключей R2. Для R2 подготовлен архив `artifacts/tower/character-sets/pilot-assets-v1.zip`: относительные ключи объектов, оригинальные файлы, размеры, MIME и SHA-256 в `manifest.json`. Доступа на запись к существующему R2 в этой сессии нет; загрузка новых файлов туда не подтверждена.

```bash
python manage.py check_character_sets
python manage.py prepare_character_assets --archive artifacts/tower/character-sets/pilot-assets-v1.zip
python manage.py prepare_character_assets --verify-public-base https://YOUR-PUBLIC-ASSET-HOST
python manage.py import_tower_chibi --dry-run
```

Проверка публичной копии выполняет ограниченные GET и сверяет размер/хеш каждого файла; успешный HTTP-статус без совпадения содержимого недостаточен. Загрузка не включается неявно и не требует публикации неподготовленных наборов.

Для остальных десяти персонажей подготовлены характеры и заглушки чиби. Их полная графика выпускается по этому стандарту на этапе 6, как предусмотрено планом. Право на набор при сборке не должно теряться из-за ожидания графики: этап 3 хранит его отдельно от готовности публикации.
