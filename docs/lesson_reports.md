# Сабмиты на уроке и PDF-отчёты

При обновлении сервера установите `requirements.txt` и выполните
`python manage.py migrate` (миграция `0031_submission_test_details`).

В режиме урока модуль кодинга показывает попытки выбранного класса. Список
обновляется каждые 3 секунды; старые попытки подгружаются кнопкой «Показать ещё».
Код, входные данные, ожидаемый/фактический вывод и ошибки каждого теста доступны
только владельцу сессии. Снимки тестов и исполняемого кода сохраняются для новых
попыток. Детали старых тестов восстановить невозможно; интерфейс сообщает об этом.

Кнопка PDF находится в аналитике экзамена и результатах взаимного оценивания.
Отчёт включает завершённые работы экзамена (и выбранного класса, если задан
фильтр). Отсутствующие оценки отмечены прочерком, исключены из среднего и не
приравниваются к нулю. Средние баллы учеников рассчитываются сначала по отзывам
для каждой работы, затем по работам, чтобы число проверяющих не меняло её вес.
Диаграммы и цветные матрицы учительских и ученических оценок раздельны.

Анализ использует существующий `OPENAI_API_KEY`. Необязательная переменная
`OPENAI_EXAM_REPORT_MODEL` задаёт модель; по умолчанию `gpt-4o-mini`.
В запрос идут вопросы, статистика, обезличенные строки баллов, все комментарии
и статусы модерации. Имена учеников и проверяющих отдельными полями не отправляются;
текст комментариев сохраняется без сокращений. Тексты с повторениями вынесены
в общий словарь. Ответ кэшируется на сутки по содержимому и языку; изменение
оценок или комментариев автоматически меняет ключ. Используется `store=False`.
Комментарии трактуются как данные, а не инструкции модели.

При сбое API, отсутствии ключа или превышении лимита входа (300 КБ UTF-8)
скачивается статистический PDF с явным сообщением об отсутствии AI-анализа.
Можно повторить скачивание либо сузить выборку по классу. Поддельный анализ
не создаётся. Запрос к OpenAI ограничен 22 секундами без автоматических повторов;
для больших отчётов рекомендуемый таймаут HTTP-обработчика — не менее 60 секунд.
Шрифты DejaVu с лицензией включены в репозиторий для кириллицы и казахского текста.

Проверки: `python manage.py test core --noinput` и
`node core/tests_lesson_markers.js`. Тесты отчётов подменяют API OpenAI, не расходуя
ключ и не отправляя учебные данные внешнему сервису.
